# Quiz Master - Java Swing Mini Project

A desktop multiple-choice quiz application prepared for a Full Stack Java Programming mini-project submission.

## Features
- Quiz categories: Mixed Quiz, Java Fundamentals, and Computer Basics
- Ten questions per attempt, with four options per question
- 15-second countdown for every question
- Instant feedback and an explanation for the correct answer
- Live score and question-progress indicator
- Final score, percentage, feedback message, and Play Again option
- Built using standard Java Swing/AWT; no external libraries or database setup required

## Requirements
- JDK 17 or later recommended
- Windows, Linux, or macOS

## Compile and run
Open a terminal in this folder and run:

```sh
javac QuizMaster.java
java QuizMaster
```

On Windows, you can double-click `run.bat`. On Linux/macOS, run `chmod +x run.sh` once and then `./run.sh`.

## Controls
1. Select a quiz category on the welcome screen.
2. Click **START QUIZ**.
3. Choose one of the four options before the 15-second timer expires.
4. Read the feedback and click **NEXT QUESTION**.
5. At the end, view your score and select **PLAY AGAIN** to restart.
